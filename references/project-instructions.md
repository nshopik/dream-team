# Project instructions

- A project's instructions are its `CLAUDE.md` and its `AGENTS.md`, whichever exist.
- Read the repo-root `AGENTS.md` when it exists; Claude Code does not load it.
- Both files exist and disagree on a rule → stop and ask the user which one wins.
- Writing a project rule → write it to `AGENTS.md` when the project has only `AGENTS.md`;
  otherwise to `CLAUDE.md`.
